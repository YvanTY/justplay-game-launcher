JustPlay - Game Launcher (portable)
===================================

Pick up any controller, choose any game, play it on any screen.

Start:   double-click JustPlay.exe (keep SDL3.dll in the same folder).
Games:   on first start, press A (or click "Find my games") to add the games on this PC.
Menu:    Start on your controller (or F1) opens settings, controllers, add games and power.

Your library and settings are saved in %APPDATA%\GameLauncher, so you can move or
update this folder without losing them.

Xbox-only games and other controllers
-------------------------------------
JustPlay can make any controller look like an Xbox controller to games that only accept
Xbox pads. That needs the free ViGEmBus driver, which the installer version sets up for you.
With this portable version, install it yourself from:
https://github.com/nefarius/ViGEmBus/releases

"Windows protected your PC"?
----------------------------
JustPlay is new and not yet digitally signed, so Windows SmartScreen may warn you the
first time. Click "More info", then "Run anyway".
